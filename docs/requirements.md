| 화면 | 경로 | 설명 |

| 관리자 - 발송 이력 | `/admin/email-logs` | admin 전용, email_logs 조회 |

## 이메일 템플릿 5종 (문안 확정 — Concept.md 5.1)

| 템플릿 키 | 트리거 | 수신자 | 제목 |
|---|---|---|---|
| `ticket_created` | 티켓 등록 | 요청자 | `[티켓 #N] 새 요청이 접수되었습니다` |
| `ticket_assigned` | 담당자 배정 | 배정된 담당자 | `[티켓 #N] 담당자로 지정되었습니다` |
| `status_changed` | 상태 변경 (resolved 제외) | 요청자 | `[티켓 #N] 처리 상태가 'X'(으)로 변경되었습니다` |
| `comment_added` | 댓글 등록 (내부 메모 제외) | 상대방 | `[티켓 #N] 새 댓글이 등록되었습니다` |
| `ticket_resolved` | 상태 → resolved | 요청자 | `[티켓 #N] 처리가 완료되었습니다` |

본문에는 티켓 번호·제목·상태·링크만 포함하고 티켓 본문 전체는 넣지 않는다 (`lib/email/templates`).

## 제외 범위 (MVP)

- 실시간 채팅 (R4 = X) — 댓글 CRUD로 대체
- SSO/LDAP 연동, 카카오/SMS 발송, 승인 결재선, SLA 자동 에스컬레이션
- 첨부파일 내용 검색, 유사 티켓 추천, 통계 리포트 export
